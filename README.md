# AI-practice

Basic to advance artificial intelligence learning and hand on experience.

## Contents

| Project | Description |
| --- | --- |
| [`youtube_transcript_extractor/`](youtube_transcript_extractor/README.md) | Extract the transcript and content of any captioned YouTube video, as `txt`, `srt`, `vtt`, `json` or `md`. Standard library only. |
| `Circular Mode of Help within Countries using AI` | Notes on a circular model of cooperation between countries. |

### Quick start

```bash
python -m youtube_transcript_extractor https://youtu.be/VIDEO_ID --format md --paragraphs
```

See the [project README](youtube_transcript_extractor/README.md) for all
options, the Python API and the design notes.
